# Pandaren world-DB SQL — Playable Pandaren (22 Alliance / 23 Horde)

Apply with `mysql acore_world < apply_all.sql` from this folder (files are idempotent).
Port scope + client/DBC build state: `00_SCOPE.md`. Deploy recipe:
`../Worgoblin/DEPLOY_RECONSTRUCTED.md`. Worldserver rebuild required
(`SharedDefines.h` + two Player.cpp racial edits, see below).

## Server DBC hand-off

**THIRD REVISION 2026-08-27 - copying .dbc files to the Linux box is NO LONGER NEEDED.**
This fork loads every DBC store as *file, then `LoadFromDB(<name>_dbc)`* (DBCStores.cpp
`LOAD_DBC`), and those `*_dbc` world tables ship EMPTY precisely so content can be added
through SQL. `11_dbc_overlay.sql` carries every server-side row, so applying `apply_all.sql`
is the whole server-side data step.

Only five stores matter server-side - **CharSections, CharHairGeosets,
CharacterFacialHairStyles and CharBaseInfo have no `LOAD_DBC` entry at all and are
CLIENT-ONLY**. The `dbc_server/` folder is kept only as a convenience mirror.
